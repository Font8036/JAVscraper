<h1 align="center">JAVscraper</h1>
<p align="center">文件名刮削与文件整理工具</p>

一个 Windows 桌面小工具：**从文件名里提取标准番号，再按番号批量移动、重命名文件**。

日常用法就是三步——选目录、点扫描、点移动。不需要懂编程，也不需要打开命令行。
需要写进脚本或计划任务时，核心的**扫描**和**移动**也可以用[命令行](#命令行模式cli)批量跑。

完整版还额外提供**网页信息抓取**（JavDB、字幕猫）和 **Jellyfin NFO 生成**，同样在图形界面里操作。

## 这个工具能做什么

假设你有一堆文件名长这样的视频：

```
ABP-123 某某标题.mp4
SSIS_456 另一个标题.mkv
FC2-1234567.mp4
随手拍的一段视频.mp4
```

**核心功能**（核心版 / CLI 版就有）：

| 能力 | 说明 |
| --- | --- |
| 识别番号 | 从文件名里认出 `ABP-123`、`SSIS-456`、`FC2-1234567` 这类标准代码；文件名里没有时，还能从**父文件夹名**继承 |
| 扫描统计 | 一次扫一个或多个目录，列出每个文件认出了什么；给出总数、直接提取、父目录继承、提取率，并记录本次耗时 |
| 导出结果 | 每次扫描自动生成 JSON（给移动功能用）、文本报告、CSV 表格；扫描页有「📂 打开最近 CSV」一键用 Excel 打开 |
| 批量整理 | 按番号建子文件夹（`目标\ABP-123\`）或平铺；文件名可保留原名或按番号重命名 |
| 分段视频 | 同一番号有多个分段时，自动重编号成 `-part1`、`-part2`（Jellyfin 按顺序播放） |
| 字幕跟随 | 附件（`.srt` / `.ass`）可跟随同目录视频命名，也可跟随目标目录里已存在的视频 |
| 撤回 | 按上一次移动的记录把文件搬回原位，支持「撤回→再撤」接着撤 |
| 安全网 | 移动前先预览；跨盘移动专门警告；目标文件被 Excel 等占用时弹出重试 / 换名 / 另存为 |
| 省事的小细节 | 扫描和移动的目录自动记住；窗口大小位置、表格列宽自动记忆；窗口可置顶 |
| 命令行 | 不开界面也能 `scan` / `move` / `undo` / `config`，与界面共用同一份配置 |

**扩展功能**（完整版才有，随程序一起发布）：

| 功能 | 作用 |
| --- | --- |
| **JavDB 信息** | 去 javdb.com 抓取演员、评分、类别、评论、封面，生成带封面嵌入的 Excel |
| **字幕猫** | 去 subtitlecat.com 搜索并下载中文字幕，完成后生成结果表格 |
| **Jellyfin NFO** | 读取刮削好的表格，为每个电影文件夹生成 Jellyfin / Kodi 能识别的 `.nfo`，并复制封面 |

**它不做什么**：不下载视频、不改动视频内容、不做媒体库管理；除抓取功能外也不联网。

## 下载与安装

软件有三个版本，按需要选一个下载即可。三个版本都是**压缩包**，解压后是一个**文件夹**：

| 版本 | 压缩包大小 | 解压后 | 包含什么 | 适合谁 |
| --- | --- | --- | --- | --- |
| **CLI 版** | 约 6.3 MB | 约 20.5 MB | 扫描 + 移动（只有命令行） | 要写脚本 / 计划任务 |
| **核心版** | 约 9.1 MB | 约 31.2 MB | 扫描 + 移动（图形界面） | 只想整理本地文件 |
| **完整版** | 约 41.5 MB | 约 149 MB | 核心功能 + 全部扩展功能 | 还要抓网站信息 / 下载字幕 / 生成 NFO |

下载对应的压缩包（文件名形如 `JAVscraper_core_vX.Y.Z_win64.7z`、`JAVscraper_full_vX.Y.Z_win64.7z`、`JAVscraper_cli.7z`），然后：

1. **解压**到任意目录（例如 `D:\Tools\JAVscraper\`），得到同名的**文件夹**；
2. 进入这个文件夹，**双击里面的 exe**：
   - 核心版 / 完整版：打开图形界面；
   - CLI 版：是一个黑窗口命令行程序，需要在 cmd / PowerShell 里调用（见[命令行模式](#命令行模式cli)）；
3. 第一次运行会在 exe 旁边自动生成 `config.json` 和 `log\` 文件夹。

> ⚠ **重要**：程序是"一个文件夹 + 一个 exe + 一堆依赖文件"的形态。
> 不要只把 exe 单独拷出来——它离不开同目录下的其他文件。

### 为什么是压缩包 + 多文件

从 **v0.5.0** 起，所有版本都改成 **PyInstaller 多文件模式（`-D`）+ 7z 压缩包**分发，原因很实际：

- **降低被拦截的概率**。单文件 exe 每次启动都要把自身解压到临时目录，行为特征很像恶意程序，Windows Defender / SmartScreen 更容易拦下来；多文件目录是普通的"小程序 + 依赖库"，误判少很多。
- **启动更快**。不用每次启动都解压几十上百 MB。
- **代价**：必须整个文件夹一起用、一起移动；不能只拷 exe。

如果 Windows 仍然提示"未知发布者"或被 Defender 拦，见[常见问题](#常见问题)里的处理办法。

### 系统要求

- Windows 10 / 11（64 位）
- 不需要安装 Python，不需要任何其他软件
- 完整版解压后约 148 MB（主要是内置浏览器驱动，体积正常）

### 升级到新版本

1. 关闭正在运行的程序；
2. 解压新版压缩包，把得到的文件夹里的内容**覆盖**到旧文件夹（或整个替换）；
3. **保留旧的 `config.json` 和 `log\`**——配置和扫描记录都在里面；
4. 双击新 exe 即可。旧版本的 exe 可以直接删掉。

## 第一次使用

1. **双击 exe 启动**。首次运行会在 exe 旁边生成 `config.json` 和 `log\`。

2. **切到「1-扫描」**，在「扫描目录」里选（或粘贴）你的视频目录——**第一次需要手动选，之后会自动记住**。
   需要同时扫几个目录就点「+ 添加目录」，每个目录一行。

3. 点「开始扫描」，等表格逐行填满。状态栏会显示总数、成功数、提取率和耗时。

4. **切到「2-移动」**：确认「目标目录」，点「预览更改」看一遍计划，再点「执行移动」。

5. 需要调参数（扩展名、命名方式、分段、冲突处理等）时，点右下角的 **「配置」** 按钮，见[配置窗口](#配置窗口)。

> 扫描目录、目标目录这些"路径"不是配置项，而是**跟着输入框的记忆**：在界面上选过一次，之后下拉里就有。配置窗口里管的是规则和参数。

到这里就能用了。下面按四个功能模块展开细节。

## 日常使用流程

主界面顶部是一排标签页，完整版会显示：

```
1-扫描   2-移动   3-爬虫   4-Jellyfin NFO
```

**所有规则类配置都集中在右下角的「配置」窗口里**，各标签页只负责操作。

---

### ① 扫描

整个流程的起点。扫描**只读不写**（除了在 `log\` 下生成结果文件），可以放心反复跑。

**操作步骤**：

1. 确认「扫描目录」。可以：
   - 直接选或粘贴一个目录；
   - 点「+ 添加目录」再加几行，一次扫描多个目录（互相包含的目录只扫一次，见下）；
   - 点输入框展开历史下拉，选之前用过的目录。
2. 点「开始扫描」；
3. 结果一行行出现在表格里，状态栏实时显示进度和耗时。

**多目录与嵌套**：

- 一个目录如果在另一个目录**里面**（比如同时加了 `D:\videos` 和 `D:\videos\新建`），程序只扫外层那个，并在日志里提示"已跳过"，不会把同一批文件扫两遍；
- 扫描结果按**绝对路径去重**，重复的目录、软链接都不会重复计数。

**看懂结果**：

| 显示 | 含义 |
| --- | --- |
| `✓` **绿色** | 从文件名成功识别到番号 |
| `↳` **蓝色** | 文件名里没有，从父文件夹名继承了番号 |
| `✗` **灰色** | 没识别到，保持原样（**不会参与移动**） |

表格上方状态栏显示：总数、成功数、提取率、耗时。点表头可以排序（例如按「状态」把 `✓` 和 `✗` 分开）。

**搜索与筛选**：

- 表格上方有搜索框，可实时筛选；
- 下拉选「全部列」或具体列名（如「文件名」）；
- 勾上「正则」时，搜索文本按正则表达式解释；
- 右键表格可「复制整行 / 复制选中的多行」（列之间用制表符分隔，直接粘到 Excel 就行）。

**结果文件与「打开最近 CSV」**：

- 每次扫描都会在 `log\<时间戳>\` 下生成三个文件：
  - `scraper_results.json`（移动功能读它）
  - `extraction_report.txt`（人可读报告，含统计与图例）
  - `extraction_table.csv`（表格，可直接用 Excel 打开）
- 扫描页右上角的 **「📂 打开最近 CSV」** 会用系统默认程序（Excel / WPS）打开最近一次的 CSV；程序启动时也会自动找到 `log\` 下最近的一份。

**结果保留上限**：

- 配置里的「结果保留上限（次）」默认 **20**：每次扫描后自动删掉最旧的记录，防止 `log\` 无限膨胀；
- 填 **0** 表示永久保留、不自动清理；
- 只删除符合 `YYYYMMDD_HHMMSS` 命名的文件夹，输出目录里你自己的文件不会被碰。

**如果 `✗` 太多**：

- 说明这些文件名里没有可识别的番号；
- 常见原因是缺少连接符（`-` 或 `_`）——比如 `ABP123` 而不是 `ABP-123`，需要手动改文件名；
- 前缀不在「已知字母前缀」里也认不出，可以到配置窗口把它们加进去；
- 识别规则在[配置窗口](#配置窗口)里可以调整。

### ② 移动

扫描完成后，切到「2-移动」。

**操作步骤**：

1. 顶部「输入 JSON」应该已经自动填好（来自上一次扫描）；
2. 确认「目标目录」（选过一次就会记住）；
3. **点「预览更改」**——这一步不会动文件，只是告诉你将会发生什么；
4. 仔细检查表格，用勾选框选择要移动的行（默认全选）；
5. 点「执行移动」，确认后开始。

**预览表格的颜色**：

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 正常移动（含按番号重命名） |
| 灰色 | 跳过（目标已存在，按「文件冲突处理」的「跳过」） |
| 红色 | 覆盖（目标已存在，会被替换）⚠ |

**勾选与筛选**：

- 每行前面有勾选框；表头的勾选框是「全选 / 全不选」，**只对当前可见的行生效**；
- 配合搜索框用：搜 `ABP`，点表头全选，就只勾上所有 ABP 相关的行；
- 下拉里还能选「已勾选 / 未勾选」，只看符合筛选条件的行。

**文件冲突处理**（配置窗口「移动」段）：

| 策略 | 行为 |
| --- | --- |
| 跳过（默认不选） | 目标已有同名文件时不动这个文件 |
| 覆盖 | 删掉已存在的目标文件再移入 ⚠ 无法找回 |
| 重命名 | 目标名加 `_01`、`_02` 后缀（默认） |

如果一批里有多个文件会写到**同一个目标路径**（只有「覆盖」时才会发生），预览阶段会弹窗提醒，说明「覆盖」会丢哪个文件。

**多视频与分段（`-part1` / `-part2`）**：

同一番号下有多个视频（分段视频）时，勾选「多视频启用 -partN 后缀」后：

- 自动比对文件名，剔除公共部分，从差异里提取序号（支持纯数字或纯单字母）；
- **按顺序重新编号**：不管是 `_A, _B` 还是 `_1, _2`，只要序号连续（1~N），都会变成 `-part1`、`-part2`……
- **必须连续**：只有 `_1` 和 `_3`（缺 2）这种跳号的，**整组放弃**重命名，退回普通规则——为了 Jellyfin 的播放顺序稳定；
- **命名主干**：「按提取码命名」时主干是提取码；「保留原文件名」时主干是剔除序号后的公共部分（例如 `ABP-123-cd1` / `ABP-123-cd2` → `ABP-123-part1` / `-part2`）。

**附件命名**（配置窗口「移动」段的「附件命名方式」）：

| 选项 | 行为 |
| --- | --- |
| 保留原文件名 | 附件保持原名（默认） |
| 按提取码命名 | 附件改为 `番号.扩展名` |
| 跟随视频命名 | 附件改为与视频同名 |

「跟随视频命名」的完整规则：

1. **优先跟随源目录里的视频**：同一源目录恰好一个视频时，附件跟它同名。
   例如 `ABP-123 某某标题.mp4` + `ABP-123-zh-CN.srt` → 移动后字幕变成 `ABP-123 某某标题.srt`。
2. **源目录没有视频时，去目标目录找**：视频已经先移到了 `目标\ABP-123\`，这次只移动字幕——程序会在 `目标\ABP-123\` 里找那个唯一视频，让字幕跟它同名。
3. **两处都找不到、或找到多个视频**（比如分段视频）：配对是模糊的，程序**不猜**，退回保留原文件名。
4. **平铺模式不启用目标目录查找**（关掉「移动到提取名子文件夹」时，目标目录里没有番号子文件夹，无从查起）。
5. 开了分段命名且成功应用时，附件跟随 **part1** 那一段。

**跨盘移动的警告**：

程序会按物理卷（`st_dev`）精确判断源和目标是否在同一块盘上：

- **同盘**：瞬间完成（重命名），照常确认后执行；
- **跨盘**：本质是「复制 + 删除」，速度明显变慢，执行前会专门弹窗警告并列出示例；确认后才会继续。

> 移动开始后**无法暂停**。跨盘移动大文件时可能长时间没反应，这是正常的。

**移错了怎么办**：

点「撤回移动」，会按上一次移动的记录把文件搬回原位。

- 撤回记录只保留**最近一次**；连续执行多次移动时，只能撤最后一次；
- 撤回**可以重复执行**：中途被打断、或有几个文件因原路径被占用没撤回去，处理好后再点一次即可接着撤；
- 有失败时记录文件会保留，方便你处理完再撤。

**界面记忆**：

- 窗口大小、位置会被记住；状态栏的「📌 置顶」也可以勾上；
- 表格的列宽可以拖，拖完会记住（按比例保存，换分辨率也不会乱）。

### ③ 爬虫（完整版）

「3-爬虫」内部有两个子标签页：

```
JavDB 信息   字幕猫
```

用法类似：给一批番号 → 自动抓取 → 生成 Excel / 下载文件。详细的配置项与排错在各插件自己的文档里：

- [JavDB 信息 + 字幕猫 完整说明](plugins/web_scraper/README.md)

#### JavDB 信息（速览）

1. 准备一个 Excel：**第一列**写番号、一行一个、不要表头；
2. 配置窗口「JavDB 信息」页填好输入 Excel、封面目录、输出 CSV、输出 Excel；
3. 切回「3-爬虫 → JavDB 信息」，点「开始爬取」；
4. 全部完成后点「生成 Excel」——完成弹窗里可以直接点「**打开**」用 Excel 看结果。

要点：

- 有些信息需要登录才可见：可在配置里「导入浏览器 Cookie」，或点「启动浏览器」手动登录后关闭；
- 第一次跑建议勾「显示浏览器窗口」，javdb 可能弹验证码，需要手动点；
- 「请求间隔」别改太快，容易被封；
- 每部影片最多抓 **10 条**评论，用中文句号连接；
- 遇到卡住可以点「停止」，已抓到的数据会保存；也可以跳过爬取，直接用已有 CSV 生成 Excel。

#### 字幕猫（速览）

1. 准备番号清单 Excel（同上）；
2. 配置窗口「字幕猫」页填好输入 Excel、目标目录、输出 Excel；
3. 切回「3-爬虫 → 字幕猫」，点「开始爬取」，完成后自动生成结果表格。

要点：

- 下载的字幕**平铺**在目标目录（不建子文件夹），文件名与网站提供的一致；
- 字幕选择优先级：番号一致 → 有 👍 → translated from Chinese → 下载量最高；
- 番号对不上的字幕**不会下载**，会在结果表里标明，需要人工核对；
- 部分字幕要等网站"翻译"生成后才能下载，程序会自动点翻译并轮询等待。

### ④ Jellyfin NFO（完整版）

读取刮削好的 Excel（通常来自 JavDB 信息），为每个电影文件夹生成 `.nfo` 元数据，并把封面复制进去。

**操作步骤**：

1. 准备两个目录：

   | 准备 | 说明 |
   | --- | --- |
   | 电影文件目录 | 每个电影一个子文件夹，文件夹名就是番号，如 `ABP-123\` |
   | 封面源目录 | 从表格里提取出来的封面图存到哪里 |

2. 配置窗口「Jellyfin NFO」页填好输入 Excel、两个目录、工作表序号、列名所在行、各字段列名、NFO 模式、封面命名；点「应用」；
3. 切回「4-Jellyfin NFO」，点「提取图片」——把 Excel 里嵌入单元格的封面抠出来；
4. 再点「生成 NFO」——遍历电影文件夹，复制封面 + 生成 `.nfo`；
5. 把「电影文件目录」加入 Jellyfin 媒体库即可。

**新版的变化**：

- 两个操作都会在状态栏显示**实时计时**，完成后日志区给出详细结果（处理数、未匹配数、跳过数、耗时）；
- 失败时会弹出错误对话框，不用去翻日志找原因；
- 「视频扩展名」直接**跟随核心配置**里的视频扩展名，不再单独维护一份。

**注意事项**：

- 只支持**嵌入单元格的封面图**（WPS「嵌入单元格图片」/ Excel 365「置于单元格中」）；普通"插入图片"（浮动图）提取不了；
- 电影文件夹名必须与 Excel 里的番号一致，否则记为「未匹配」；
- 生成的 NFO 是 UTF-8 的 XML，可以直接用记事本打开；
- 详细的列名配置与排错见 [Jellyfin NFO 插件文档](plugins/jellyfin_nfo/README.md)。

## 命令行模式（CLI）

**扫描**和**移动**可以完全不开界面。爬虫和 Jellyfin NFO 只在图形界面里提供。

CLI 版和界面版**共用同一份配置**：把 `JAVscraper_cli` 文件夹和界面版文件夹放在一起（或让它们指向同一个 `config.json`）即可共享规则和 `log\`。

```
JAVscraper_core_vX.Y.Z_win64\  ← 图形界面（核心版）
JAVscraper_cli\                ← 命令行（只有 exe 和依赖）
```

> 用 pip 安装的话，把下面的 `JAVscraper_cli.exe` 换成 `av-scraper` 即可。
> 命令行版没有版本号后缀，方便加进 PATH、反复敲；版本用 `JAVscraper_cli.exe --version` 看。

### 扫描

```cmd
:: 扫描 D:\videos，结果自动存进 log\<时间戳>\（JSON + 文本报告 + CSV）
JAVscraper_cli.exe scan D:\videos

:: 一次扫多个目录（互相包含的目录只会扫一遍）
JAVscraper_cli.exe scan D:\videos D:\downloads

:: 报告换个地方放（默认 log\<时间戳>\）
JAVscraper_cli.exe scan D:\videos --output-dir D:\reports

:: 只保留最近 5 次扫描结果（覆盖配置里的「结果保留上限」；0 = 不清理）
JAVscraper_cli.exe scan D:\videos --keep 5

:: 只在屏幕上看看结果，不写任何文件
JAVscraper_cli.exe scan D:\videos --no-reports

:: 把 JSON 交给下一条命令：- 表示写到标准输出（摘要走 stderr）
JAVscraper_cli.exe scan D:\videos --json - > results.json
```

输出示例：

```
扫描目录    D:\videos
文件总数    5
直接提取    3
父目录继承  0
保持原样    2
提取率      60.0%

未识别（2）：
  - random.mkv
  - 随手拍的一段视频.mp4
```

未识别的文件不会被动，认出来的才参与下一步。一次扫多个目录时，「扫描目录」下面会逐个列出来；某个目录在另一个目录里面时，只在 stderr 提醒一句「……在……里面，已跳过」。

### 移动

**先加 `--dry-run` 看一遍**，它就是界面里的「预览更改」：

```cmd
:: 预览：只告诉你会发生什么，一个文件都不动
JAVscraper_cli.exe move results.json -t E:\sorted --dry-run

:: 确认没问题再执行（-y = 不再问一次）
JAVscraper_cli.exe move results.json -t E:\sorted -y

:: 只处理其中几个番号（相当于界面里勾选几行）
JAVscraper_cli.exe move results.json -t E:\sorted -y --only ABP-123,SSIS-456

:: 目标已有同名文件时改成覆盖（默认是「重命名」，加 _01）
JAVscraper_cli.exe move results.json -t E:\sorted -y --on-conflict overwrite

:: 分段视频重新编号成 -part1、-part2
JAVscraper_cli.exe move results.json -t E:\sorted -y --part-naming
```

| 参数 | 说明 |
| --- | --- |
| `-t, --target DIR` | 目标目录。不写就用配置里的（界面上选过一次就会记住） |
| `--dry-run` | 只预览，不动文件 |
| `-y, --yes` | 不再确认。**在脚本或计划任务里必须加**，否则会拒绝执行 |
| `--only 番号[,番号]` | 只处理这些番号 |
| `--folder` / `--no-folder` | 是否按番号建子文件夹（默认跟配置） |
| `--video-naming` | `keep` 保留原文件名 / `code` 按番号命名 |
| `--attachment-naming` | `keep` / `code` / `follow`（跟随视频） |
| `--part-naming` / `--no-part-naming` | 分段视频按 `-part1`、`-part2` 重新编号（默认跟配置） |
| `--on-conflict` | `skip` 跳过 / `overwrite` 覆盖 / `rename` 加 `_01`（默认跟配置） |

预览里还会显示「分段命名」是否启用、以及**跨盘移动的数量**；如果有文件要跨盘（复制 + 删除，会明显变慢），会在 stderr 单独提醒并给出例子。

### 撤回

命令行移的文件可以回界面点「撤回移动」；界面移的也能用命令撤。两边共用 `log\move_operations.json`（只保留最近一次）。

```cmd
JAVscraper_cli.exe undo --dry-run    :: 先看看会撤回什么
JAVscraper_cli.exe undo -y           :: 真的撤回
```

撤回可以重复执行：中途 Ctrl+C、或有几个文件因原路径被占用没撤回去，处理好后再跑一次即可，已经撤回去的会自动跳过。

### 看当前配置

```cmd
JAVscraper_cli.exe config          :: 列出当前生效的配置
JAVscraper_cli.exe config --path   :: 只打印配置文件在哪
```

命令行**不会修改配置**，要改配置请用界面的「配置」窗口。

### 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 成功（包括"没有需要处理的文件"） |
| 1 | 有文件没处理成功 / 被中断 / 你自己取消了 |
| 2 | 参数用法问题（包括非交互环境里少了 `--yes`） |

每个子命令都可以加 `-v` 看每个文件的明细，或 `-q` 只在出错时出声。完整参数说明：

```cmd
JAVscraper_cli.exe --help
JAVscraper_cli.exe move --help
```

### 在批处理脚本里的典型写法

```bat
@echo off
set CLI="D:\Tools\JAVscraper\JAVscraper_cli\JAVscraper_cli.exe"

%CLI% scan D:\downloads --json D:\temp\scan.json --no-reports
if errorlevel 1 goto :fail

%CLI% move D:\temp\scan.json -t E:\sorted --dry-run
%CLI% move D:\temp\scan.json -t E:\sorted -y
if errorlevel 1 goto :fail
exit /b 0

:fail
echo 整理失败，见上方输出
exit /b 1
```

## 配置窗口

主界面右下角的 **「配置」** 按钮会打开一个独立窗口。规则类设置都在这里，各标签页只负责操作。

**窗口结构**：

```
[核心配置]  [JavDB 信息]  [字幕猫]  [Jellyfin NFO]
─────────────────────────────────────────
（当前标签页的所有配置项）
─────────────────────────────────────────
[重置]  [重新加载]         [确定]  [取消]  [应用]
```

**底部按钮**：

| 按钮 | 作用 |
| --- | --- |
| 重置 | 恢复**出厂默认值**并立即保存（会二次确认） |
| 重新加载 | 从磁盘重读配置，放弃当前未保存的修改 |
| 确定 | 保存并关闭 |
| 取消 | 放弃修改并关闭 |
| 应用 | 保存但不关闭窗口 |

### 核心配置：扫描

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 输出目录 | 空 | 结果存哪里；空 = 自动用 `log\` |
| 结果保留上限（次） | 20 | 最多保留几次扫描结果，超出的自动删最旧；**0 = 不清理** |
| 递归处理子文件夹 | 开 | 关掉只扫第一层 |
| 从父目录继承番号 | 开 | 文件名没有番号时，用父文件夹名再认一次 |
| 扩展名分组 | 默认 | 切换不同的扩展名组合，见下 |
| 连接符 | `-` `_` | 番号和分隔符之间允许哪些字符 |
| 视频扩展名 | 常见视频格式 | 按"视频"归类，供移动页的命名规则使用 |
| 附件扩展名 | `.srt` `.ass` | 按"附件"归类 |
| 已知字母前缀 | 内置 400+ | 番号前缀白名单，不在里面的前缀认不出 |

**扩展名分组**（替换了以前"直接改两个扩展名列表"的做法）：

- 下拉可切换分组，每个分组有自己的视频 / 附件扩展名组合；
  例如"只扫视频""视频+字幕""整盘镜像"；
- 切换分组时，**自动保存当前文本框里的修改**，再载入所选分组；
- 点下拉旁的「管理」可以**新建 / 删除 / 重命名**分组；
- 「默认」分组不能删除、不能重命名。

### 核心配置：移动

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 移动到提取名子文件夹 | 开 | 开 = 每个番号一个子文件夹；关 = 全部平铺到目标目录 |
| 视频命名方式 | 保留原文件名 | 或「按提取码命名」 |
| 附件命名方式 | 保留原文件名 | 或「按提取码命名」/「跟随视频命名」 |
| 多视频启用 -partN 后缀 | 关 | 分段视频重编号成 `-part1`、`-part2` |
| 文件冲突处理 | 重命名 | 跳过 / 覆盖 / 重命名（加 `_01`） |

### 核心配置：应用

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 关闭时二次确认 | 开 | 关窗口时弹窗确认，避免误关 |
| 启动时检查更新 | 关 | 启动 3 秒后静默查询 GitHub 最新版本；有新版弹窗，已是最新则只在状态栏提示 |
| 历史目录上限 | 5 | 路径输入框下拉里最多保留多少条历史 |
| 日志区高度（行） | 8 | 各页面日志区高度 |
| 表格区高度（行） | 10 | 各页面表格最小高度（表格会随窗口拉伸） |
| 界面缩放（%） | 100 | 100 = 系统默认；150 = 放大 50%，重启后生效 |

> 提示：有些内部字段（如表格列宽、窗口位置、各扩展名分组的明细）写在 `config.json` 里但不在配置窗展示，属于自动记忆，不用管。

**修改生效**：大部分配置点「应用」后立即生效；缩放需要重启。

## 常见问题

**Q：为什么现在只有压缩包，没有单文件 exe 了？**

从 v0.5.0 起统一改成多文件 + 7z 分发，主要是为了降低 Windows Defender / SmartScreen 的误拦概率（单文件 exe 的自解压行为太像恶意程序）。代价是必须整个文件夹一起用。详见[为什么是压缩包 + 多文件](#为什么是压缩包--多文件)。

**Q：Windows 提示"未知发布者" / 被 Defender 拦下怎么办？**

- 这是未做代码签名的程序的正常提示，点「更多信息 → 仍要运行」即可；
- 若被 Defender 直接隔离：在「Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项」里把这个文件夹加进去，然后重新解压；
- 国产安全软件（360、火绒等）有时也会拦，同样加白名单。

**Q：双击 exe 没反应 / 闪退？**

- 确认是**整个文件夹**都在，没有只拷 exe；
- 看同目录的 `log\` 有没有日志；
- 检查杀软是否拦截；
- 完整版首次启动较慢（要加载浏览器驱动），等几秒。

**Q：扫描时感觉卡住了？**

- 日志区和状态栏会实时显示进度、已扫描数量和耗时；
- 网络盘、机械盘、几万个文件时会慢一些；
- 新版目录遍历用 `os.scandir`，比旧版快 3~5 倍，一般本地盘几千个文件只需一两秒。

**Q：扫描结果里 `✗` 很多怎么办？**

- 打开配置窗口确认前缀在「已知字母前缀」里，不在就加上；
- 检查文件名里是否有合法连接符（`-` 或 `_`）；
- 文件名确实没有番号的，只能手动改名——程序不会猜。

**Q：移错了想反悔？**

- 点「撤回移动」（命令行用 `undo`）。前提是 `log\move_operations.json` 还在，且之后没有执行过新的移动；
- 撤回只保留最近一次；如果有文件没撤回去，日志会说明原因（比如原路径又被占用），处理完再点一次。

**Q：跨盘移动特别慢，正常吗？**

- 正常。跨盘本质是「复制 + 删除」，大文件可能要很久，而且**无法暂停**；
- 程序执行前会专门弹窗警告；想更快就把源目录和目标目录放在同一块物理盘上。

**Q：`log\` 会不会越积越大？**

- 扫描结果默认只保留最近 20 次（可改，0 = 不清理），每次扫描后自动删最旧的；
- 移动记录 `move_operations.json` 只保留最近一次，不会增长；
- 也可以随时手动删 `log\` 里的旧文件夹。

**Q：想直接用 Excel 看上次的扫描结果？**

- 扫描页右上角「📂 打开最近 CSV」；或用 `log\<时间戳>\extraction_table.csv`。

**Q：爬虫标签页没显示？**

- 核心版 / CLI 版不含爬虫功能，看不到是正常的；
- 完整版如果某页显示红色错误提示，说明该插件依赖缺失或加载失败，提示里会写出原因和修法。

**Q：抓取 javdb 时总是搜错番号？**

- 看生成的 Excel 里有没有**浅黄**（番号不一致）或**浅红**（没抓到）的行；
- 建议先打开「显示浏览器窗口」看一次实际搜索行为；
- 需要登录才能看的信息，先按 JavDB 文档导入 Cookie。

**Q：字幕猫下载的字幕名字对不上视频？**

- 看结果表里状态是不是「下载成功（番号不一致）」，这类行需要人工核对；
- 番号一致但文件名不好看没关系：用本工具的「移动」+「附件跟随视频命名」就能自动改成与视频同名。

**Q：怎么清空历史目录记录 / 恢复默认配置？**

- 恢复默认：配置窗口点「重置」，或删掉 `config.json` 重启；
- 只清历史：关闭程序，用记事本打开 `config.json`，把 `recent_scan_dirs`、`recent_target_dirs` 改成 `[]`。

**Q：配置文件在哪？**

- 跟 exe 放一起：核心是 `config.json`；爬虫插件是 `scraper_config.json`；NFO 插件是 `jellyfin_nfo_config.json`。

**Q：怎么知道有没有新版本？**

- 配置里打开「启动时检查更新」（默认关），或在「关于」窗口里点「检查更新」；
- 「关于」里还能看到版本号、版权信息、GitHub 仓库和问题反馈链接。

**Q：窗口位置 / 列宽乱了？**

- 程序会记住主窗口、配置窗口的位置和大小，以及表格列宽；
- 换显示器后如果位置跑丢，程序会自动丢弃屏幕外的坐标；
- 实在乱了就删掉 `config.json` 里的 `window_geometries` / `table_column_weights`，或点「重置」。

## 重要提醒

- **移动是不可逆的物理操作**。虽然有撤回，但只在"记录文件还在、之后没执行过新移动"时有效。**执行前务必点「预览更改」**，尤其看清红色的「覆盖」行。
- 扫描不修改文件，可以放心反复运行。
- **移动开始后无法暂停**，跨盘移动尤其慢；请确保源目录和目标目录尽量在同一块硬盘上。
- 本工具仅用于本地文件整理。请确保所处理的文件来源合法，并遵守当地法律法规。
- 完整版体积较大（解压后约 148 MB），因为内置了浏览器驱动，属正常现象。
- **不要单独拷贝程序里的 exe**——整个文件夹要一起复制或移动。
