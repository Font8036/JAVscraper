# JavDB 刮削插件

从 javdb.com 抓取影片元数据（演员、评分、类别、评论、封面），生成带封面嵌入的 Excel 报告。

## 功能

- 从 Excel 读取番号清单（第一列，一行一个）
- 用 Playwright 打开 javdb.com，逐个搜索并抓取详情页
- 下载封面图到本地，按番号命名
- 自动识别搜索结果是否为期望番号（不匹配时标红）
- 解析演员、评分、类别、个人/网友评论
- 生成三份文件：原始 CSV、封面图片、带封面嵌入的 Excel 报告

## 依赖

```cmd
conda activate private
pip install playwright pandas xlsxwriter httpx Pillow
playwright install msedge
```

| 包 | 用途 |
|---|---|
| `playwright` | 浏览器自动化，绕过 javdb 的动态页面 |
| `pandas` | 读写 Excel/CSV |
| `xlsxwriter` | 生成带封面嵌入的 Excel |
| `httpx` | 异步下载封面图片 |
| `Pillow` | 读取图片尺寸，用于自动设置行高 |

`playwright install msedge` 需要下载浏览器驱动（几百 MB），**只需执行一次**。

完整版 exe 已内置以上依赖，无需手动安装。

## 配置项

插件的配置保存在 `plugins/javdb/config.json`（源码运行）或 exe 同级的 `javdb_config.json`（完整版打包）。所有字段都能在插件界面里可视化编辑。

### 路径

| 字段 | 类型 | 说明 |
|---|---|---|
| `input_excel` | str(file) | 番号清单 Excel 路径 |
| `cover_dir` | str(dir) | 封面图片保存目录（不存在会自动创建） |
| `output_csv` | str(file) | 中间结果 CSV 路径 |
| `output_excel` | str(file) | 最终 Excel 报告路径 |
| `state_file` | str(file) | 登录状态文件路径（可留空） |

### 运行参数

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `show_browser` | bool | `true` | 是否显示浏览器窗口 |
| `browser_channel` | choice | `msedge` | 浏览器通道：`msedge` / `chrome` / `chromium` |
| `request_delay` | float | `1.0` | 每次请求之间的等待（秒） |
| `page_timeout` | int | `60` | 页面操作超时（秒），首次打开主页会用到 5 倍 |
| `max_retries` | int | `2` | 单个番号失败后的重试次数 |

### 行为开关

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `skip_existing_covers` | bool | `false` | 跳过已存在的封面文件 |
| `save_state_on_exit` | bool | `false` | 退出时把登录状态回写到 `state_file` |

## 使用步骤

### 1. 准备番号清单

新建一个 Excel 文件，**第一列**写入要刮削的番号，**一行一个**，不要表头：

```
ABP-123
SSIS-456
FC2-1234567
```

建议从「① 扫描」页的扫描结果里挑出 `✓` 的番号，或直接复制 `log/<时间戳>/extraction_table.csv` 里的「提取出的信息」列。

### 2. 填写配置

切到 ④ JavDB 刮削 标签页，按表格从上到下填：

```
输入 Excel:   [番号清单.xlsx_____________] [浏览…]
封面目录:     [D:\Covers\_________________] [浏览…]
输出 CSV:     [D:\Result\raw.csv__________] [浏览…]
输出 Excel:   [D:\Result\report.xlsx______] [浏览…]
登录状态:     [D:\Result\javdb_state.json_] [浏览…] [导入浏览器 Cookie]

☑ 显示浏览器窗口   浏览器: [msedge ▾]
请求间隔: [1.0] 秒   超时: [60] 秒   重试次数: [2]

☐ 跳过已存在的封面   ☐ 退出时保存登录状态

[保存配置] [开始爬取] [停止] [生成 Excel]  状态: 就绪
```

填完点 **保存配置**。

### 3. 登录 javdb（可选）

javdb 有部分信息需要登录才能看到。如果你已经在浏览器登录：

1. 在浏览器里安装 **Cookie-Editor** 或 **EditThisCookie** 扩展；
2. 打开 javdb.com，确认已登录（或至少通过了年龄验证）；
3. 用扩展导出 cookies，**选 JSON 格式**；
4. 回到插件界面，点 **导入浏览器 Cookie**，选中刚才导出的 JSON 文件；
5. 弹窗提示导入成功即可。

也可以跳过这一步，用游客模式跑，能抓到的信息会少一些。

### 4. 开始爬取

1. 点 **开始爬取**；
2. 进度表格逐行显示：

   ```
   目标番号     实际番号     名称                        状态
   ABP-123     ABP-123     某某标题                    ✓ 完成
   SSIS-456    SSIS-456B   别的标题                    ⚠ 完成（番号不同）
   FC2-…       —           —                           进行中…
   XYZ-999     —           —                           ✗ 失败：timeout
   ```

3. **如果开启了「显示浏览器窗口」**，会看到一个 Chromium 窗口自动操作。遇到验证码时手动点一下；
4. 中途想停：点 **停止**，已抓取的数据会保存；
5. 全部完成后状态栏显示 `爬取完成，共 N 条`。

#### 状态颜色

| 颜色 | 含义 |
|---|---|
| 绿色 `✓ 完成` | 刮削成功，且番号与目标一致 |
| 橙色 `⚠ 完成（番号不同）` | 刮削成功，但搜到的第一个结果番号与目标不符 |
| 红色 `✗ 失败：xxx` | 该番号未能抓取 |
| 蓝色 `进行中…` | 正在处理 |
| 灰色 `○ 已停止` | 用户手动停止 |

### 5. 生成 Excel

1. 点 **生成 Excel**；
2. 几秒后弹窗提示完成；
3. 打开输出路径下的 `.xlsx` 文件查看。

可以跳过爬取步骤，直接用已有的 CSV 生成 Excel——只要 `output_csv` 路径下的文件存在即可。

## 输出说明

### 输出 CSV

`output_csv` 路径下的 CSV 包含以下列：

| 列 | 内容 |
|---|---|
| `目标番号` | 用户输入的番号 |
| `链接` | 详情页 URL |
| `番号` | 详情页显示的番号 |
| `名称` | 标题 |
| `信息` | 详情页文本，用于二次解析 |
| `评论` | 评论文本 |

这是中间产物，用于追溯和重跑。想重新生成 Excel 时不必重新爬取。

### 封面图片

`cover_dir` 下的图片按番号命名：`ABP-123.jpg`、`SSIS-456.jpg` 等。扩展名取决于 javdb 返回的图片格式，可能是 `.jpg` / `.webp` / `.png`。

### 最终 Excel

Excel 的列布局：

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| 目标番号 | 番号 | 封面 | 名称 | 演员 | (空) | 评分 | 类别 | (空) | 评论 |

宽度和行高自动调整，封面图片嵌入到 C 列，行高按图片宽高比自动计算。

#### 行颜色

| 颜色 | 含义 |
|---|---|
| 无底色 | 正常行，目标番号与刮到的番号一致 |
| **浅红 `#FFC7CE`** | 目标番号与刮到的番号**不一致**，需要人工核对 |
| **浅黄 `#FFF2CC`** | 该番号**刮削失败**，只有目标番号，其余留空 |

这三种颜色在 Excel 里一眼可分，不用逐行去对比。

## 结果校对

因为搜索逻辑是"点击第一个结果"，实际刮到的番号不一定与目标一致（可能是续集、同系列其他作品）。建议：

1. 打开 Excel，先扫一遍**浅红**的行；
2. 对比「目标番号」与「番号」两列，判断是否是你要的那个；
3. 如果是误抓，删掉那行或手工修正；
4. **浅黄**的行是彻底没抓到的，可以重跑（单独把它们的番号放进新的 Excel）。

## 常见问题

**Q：导入 Cookie 后，爬取时还是未登录？**

- 确认导出的 JSON 是从**已登录的浏览器**导出的；
- Cookie 有时效性，过期后需要重新导出；
- 有些扩展默认只导出当前站点，如果浏览的是镜像域名可能导出为空。

**Q：被 Cloudflare 拦截 / 无限验证码？**

- **开启「显示浏览器窗口」**，手动完成验证码；
- **不要贪快**：`request_delay` 保持 ≥ 1.0 秒；
- 长时间爬取建议中途休息；
- 使用登录状态能显著降低被拦频率。

**Q：爬取很慢？**

- 每个番号通常需要 5~10 秒，100 个番号约 10~15 分钟；
- 主要耗时在等待页面加载和 Cloudflare 检查；
- 减少 `request_delay` 会加快速度，但更容易被封。

**Q：封面下载失败？**

- 检查网络是否能访问 javdb 的 CDN；
- 检查 `cover_dir` 是否有写权限；
- 部分番号可能本身就没有封面。

**Q：Excel 打开后图片不显示？**

- 确认 `cover_dir` 下存在与番号同名的图片文件；
- 部分老旧 Excel 版本对 `embed_image` 支持不好，建议用 Excel 2016+ 或 WPS 打开。

**Q：结果里有很多「番号不同」？**

- 说明搜索关键词没有精确匹配到你要的那个；
- 可以尝试用更完整的番号格式（如 `FC2PPV-1234567` 而不是 `FC2-1234567`）；
- 也可以手动在浏览器里搜一次，看 javdb 的第一个结果到底是什么。

**Q：重跑时怎么跳过已经成功的？**

- 勾选「跳过已存在的封面」可以省去封面下载；
- 但没有"跳过已成功的番号"选项，每次都会重爬全部。可以手动从输入 Excel 里删掉已成功的番号再跑。

**Q：`.csv` 里为什么有目标番号与实际番号不一致的行？**

- 这就是搜索的客观结果，不是 bug；
- 见「结果校对」一节。

## 重要提醒

- **首次跑建议开启浏览器窗口**，方便观察和手动过验证码；
- **登录状态文件包含你的身份凭证**，不要分享给他人，也不要提交到 git；
- **爬取频率不要过高**，既是为了避免被封，也是对网站的基本尊重；
- 本插件仅用于个人资料整理，请遵守 javdb 的服务条款和当地法律法规。
