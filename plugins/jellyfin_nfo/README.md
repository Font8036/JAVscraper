从刮削表格中提取封面，并生成 Jellyfin 兼容的 `.nfo` 元数据文件。

## 功能

本插件把「JavDB 刮削插件」生成的表格转换为 Jellyfin 可识别的本地元数据。它做两件事：

1. **提取图片**：从表格文件里提取所有嵌入的封面图（原始尺寸），按番号命名保存到本地目录；
2. **生成 NFO**：读取表格里的演员、评分、类别、评论等信息，为每个电影文件夹生成 `.nfo` 文件，并把封面复制到电影文件夹里。

两者相互独立，可以单独使用。通常先用「提取图片」把封面抠出来，再「生成 NFO」时用这些封面。

---

## 依赖

```cmd
conda activate private
pip install openpyxl
```

只需要 `openpyxl`。如果提取的封面需要缩放，另需 `Pillow`，但本插件不缩放，所以不强制。

完整版 exe 已内置依赖，无需手动安装。

## 配置项

插件的配置保存在 `plugins/jellyfin_nfo/config.json`（源码运行）或 exe 同级的 `jellyfin_nfo_config.json`（完整版打包）。所有字段都能在插件界面里可视化编辑。

### 路径

| 字段 | 类型 | 说明 |
|---|---|---|
| `input_excel` | str(file) | 输入表格路径（通常是 JavDB 插件生成的 `.xlsx`） |
| `movie_root` | str(dir) | 电影文件夹根目录（每个子文件夹是一个电影，文件夹名是番号） |
| `cover_source_dir` | str(dir) | 封面源目录（提取图片的输出目录，也是生成 NFO 时的封面来源） |

### Excel 解析

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `sheet_index` | int | `1` | 工作表序号，从 1 开始 |
| `header_row` | int | `1` | 列名所在的行号 |
| `code_column` | str | `番号` | 番号列名（**单列**） |
| `cover_column` | str | `封面` | 封面列名（**单列**） |
| `title_column` | str | `标题` | 标题列名（**单列**） |
| `actor_columns` | str | `演员` | 演员列名（**多列**，用 `,` 分隔） |
| `rating_columns` | str | `评分` | 评分列名（**多列**） |
| `genre_columns` | str | `类别` | 类别列名（**多列**） |
| `personal_comment_columns` | str | `个人评论` | 个人评论列名（**多列**） |
| `user_comment_columns` | str | `网友评论` | 网友评论列名（**多列**） |

**「单列」和「多列」的区别：**

- **单列**字段（番号、封面、标题）：表格里只能有一个对应名称的列；
- **多列**字段（演员、评分、类别、评论）：表格里可以有多个对应名称的列，插件会把它们的内容合并。合并规则见下方 [列名配置详解](#列名配置详解)。

### NFO 选项

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `nfo_mode` | choice | `per_video` | NFO 文件名模式：见下表 |
| `cover_naming` | choice | `both` | 封面命名模式：见下表 |
| `copy_cover` | bool | `true` | 是否把封面复制到电影文件夹 |
| `overwrite_existing` | bool | `false` | 是否覆盖已存在的 NFO 文件 |

**NFO 模式**：

| 值 | 界面显示 | 行为 |
|---|---|---|
| `per_video` | 每个视频生成同名 NFO | 生成 `<视频名>.nfo` |
| `movie_nfo` | 只生成 movie.nfo | 生成一个 `movie.nfo` 放在文件夹里 |
| `both` | 两种都生成 | 同时生成上面两种 |

**封面命名模式**：

| 值 | 界面显示 | 行为 |
|---|---|---|
| `same_as_video` | 与视频同名 | `ABC-123.mp4` → 复制出 `ABC-123.jpg` |
| `code` | 用番号命名 | 直接复制出 `ABC-123.jpg`（番号本身） |
| `both` | 两种都复制 | 上面两种都做 |

对绝大多数情况，`same_as_video` 和 `code` 生成的文件名一样（因为视频文件名通常就是番号），只有在视频文件名带有额外后缀时才会不同。

## 使用步骤

### 1. 准备表格文件

表格必须满足：

- **列名行**（默认第 1 行）有可识别的列标题；
- **番号列**：唯一标识一部电影的列；
- **封面列**：使用「嵌入单元格图片」（WPS 的 DISPIMG 格式，或 Excel 365 的「置于单元格中」）；
- 其他列：标题、演员、评分、类别、个人评论、网友评论，可选。

如果你用的是 **JavDB 刮削插件**生成的表格，默认布局已经满足要求，直接用即可。

如果你自己用 WPS / Excel 手工整理表格，需要保证封面是以「嵌入单元格图片」的方式插入的——**不能**是普通「插入图片」的浮动图片。判断方法：

- 单元格里能直接看到图片缩略图（就像内容是图片一样）；
- 点击单元格，编辑栏里显示 `=DISPIMG("ID_...",1)` 或类似公式。

### 2. 填写配置

切到 ④ Jellyfin NFO 标签页：

```
输入 Excel:      [report.xlsx_______________] [浏览…]
电影文件目录:    [D:\Movies\_________________] [浏览…]
封面源目录:      [D:\Covers\_________________] [浏览…]

第 [1] 个工作表，第 [1] 行是列名
提取的信息:   番号      封面      标题      演员       评分      类别      个人评论     网友评论
列名为：      [番号]    [封面]    [标题]    [演员]    [评分]    [类别]    [个人评论]   [网友评论]

NFO 模式: [每个视频生成同名 NFO ▾]   封面命名: [两种都复制 ▾]
☑ 复制封面   ☐ 覆盖已有 NFO

[保存配置]  [提取图片]  [生成 NFO]   状态: 就绪
```

填写要点：

- **第 N 个工作表**：表格有多个 Sheet 时，填目标 Sheet 的序号（从 1 开始）；
- **第 M 行是列名**：列名所在的行号（通常第 1 行）；
- **列名**：填表格里实际出现的表头文字；
- 演员、评分、类别、个人评论、网友评论支持多列，用 `,` 分隔（详见下一节）。

填完点 **保存配置**。

### 3. 提取封面

点 **提取图片**。日志区会实时显示：

```
从表格读取到 N 个 DISPIMG 引用
从表格内部建立 M 个 ID → 图片文件的映射
已导出 ABC-123.jpg
已导出 DEF-456.jpg
...
```

完成后弹窗提示成功导出的张数。

**输出位置**：`cover_source_dir` 配置的目录，文件名是 `<番号>.<扩展名>`。

**注意**：这一步**不会修改**原表格文件，提取是只读的。

### 4. 生成 NFO

点 **生成 NFO**。插件会：

1. 读取表格数据；
2. 遍历 `movie_root` 下的每个子文件夹；
3. 用子文件夹名匹配番号，找到对应的数据；
4. 从 `cover_source_dir` 找到封面并复制到电影文件夹；
5. 按配置的 NFO 模式生成 `.nfo` 文件。

进度表格逐行显示：

```
番号          视频数   封面    NFO     状态
ABC-123       1       ✓       ✓       完成
DEF-456       3       ✓       ✓       NFO×4
GHI-789       0       —       —       无视频文件
JKL-012       —       —       —       未匹配
```

颜色含义：

| 颜色 | 含义 |
|---|---|
| 绿色 | 完全成功 |
| 橙色 | 部分成功（未找到封面、未找到视频、未匹配） |
| 红色 | 处理失败 |

### 5. 添加到 Jellyfin

1. 打开 Jellyfin 管理后台；
2. 媒体库 → 添加媒体库 → 选择「电影」类型；
3. 文件夹指向 `movie_root`；
4. 保存，Jellyfin 会自动扫描并读取每个文件夹里的 `.nfo` 和封面。

## 列名配置详解

### 单列字段

**番号列**：用于匹配电影文件夹名，必须有且只有一个。

**封面列**：用于提取图片，必须有且只有一个。如果你的表格没有专门的封面列（比如封面和番号放在同一列），需要先手工调整表格结构。

**标题列**：显示在 NFO 的 `<title>` 里，可选。留空时会用番号代替。

### 多列字段

**演员列**：可以配多个演员列（如「主演」「配角」分开）。合并规则是**按名字去重后取并集**——不同列里如果出现同一个演员，只保留一次。

**类别列**：可以配多个类别列（如「主类别」「附加类别」）。同样**取并集去重**。

**评分列**：可以配多个评分列（如「站内评分」「豆瓣评分」）。生成 NFO 时会**按顺序生成多个 `<rating>` 标签**，每个评分独立保留。

**个人评论列**：可以配多个。生成 NFO 时**按列的顺序拼接**，列与列之间用换行分隔。

**网友评论列**：同个人评论。

### 多列的写法

假设你的表格里有三列演员：「主演」「配角」「客串」，那么：

```
演员列名: 主演,配角,客串
```

用**半角逗号**、**全角逗号**、**分号**分隔都行：

```
演员列名: 主演，配角；客串
```

### 常见列名配置示例

| 表格场景 | 推荐配置 |
|---|---|
| JavDB 插件的输出 | 全部保持默认 |
| 自己做的表格，列名是英文 | `code_column: 番号` → 改成 `id` 或 `code` |
| 演员分主配两列 | `actor_columns: 主演,配角` |
| 有两个评分来源 | `rating_columns: 评分,豆瓣评分` |
| 评论分长评和短评 | `personal_comment_columns: 长评,短评` |

## 输出说明

### 封面文件

| 位置 | 文件名 | 来源 |
|---|---|---|
| `cover_source_dir` | `<番号>.jpg` | 从表格提取的原始尺寸图片 |
| `movie_root/<番号>/` | `<视频名>.jpg` | 从 `cover_source_dir` 复制的副本 |
| `movie_root/<番号>/` | `<番号>.jpg` | 同上，用番号命名的副本 |

### NFO 文件

NFO 是 XML 格式，包含：

```xml
<?xml version="1.0" encoding="utf-8"?>
<movie>
  <title>ABC-123 某某标题</title>
  <id>ABC-123</id>
  <uniqueid type="custom">ABC-123</uniqueid>

  <rating name="database" votes="18">4.0</rating>
  <criticrating>4.0</criticrating>

  <genre>类别1</genre>
  <genre>类别2</genre>

  <actor>
    <name>张三</name>
    <role>张三丰</role>
    <type>Male</type>
  </actor>

  <plot>【个人评价】
...
【网友评论】
...</plot>
  <outline>...</outline>

  <thumb>ABC-123.jpg</thumb>
</movie>
```

### NFO 命名

根据 `nfo_mode` 配置：

| 模式 | 生成的文件 |
|---|---|
| `per_video` | `ABC-123.nfo`（视频文件名去掉扩展名） |
| `movie_nfo` | `movie.nfo` |
| `both` | 上面两个都生成 |

对单视频文件夹，推荐 `per_video`；对多分段视频（`ABC-123.part1.mp4`、`ABC-123.part2.mp4`），推荐 `both`。

## 常见问题

**Q：提取图片后目录里没有文件？**

- 检查表格里的封面是不是「嵌入单元格图片」——如果只是普通插入的浮动图片，本插件无法提取；
- 检查日志里的错误信息，通常会明确说明是封面列名不对还是格式不支持；
- 用 WPS 打开表格，点一下封面所在的单元格，编辑栏应该显示 `=DISPIMG(...)`。

**Q：列名找不到？**

- 检查 `header_row` 是不是列名所在的行；
- 检查 `sheet_index` 是不是目标工作表；
- 日志会打印当前表格里可用的列名，对照修改即可。

**Q：生成的 NFO 里没有封面？**

- 检查 `cover_source_dir` 下有没有 `<番号>.jpg`；
- 检查 `copy_cover` 有没有勾上；
- 检查电影文件夹名是否与番号完全一致（包括大小写）。

**Q：多分段视频怎么处理？**

- 用 `per_video` 模式：每个分段生成同名 NFO，Jellyfin 会识别为同一个电影的不同部分；
- 或 `both` 模式：同时生成 `movie.nfo` 作为文件夹级别的元数据。

**Q：Jellyfin 没有读取 NFO？**

- Jellyfin 默认从 `movie.nfo` 或与视频同名的 `.nfo` 读取；
- 检查媒体库的元数据设置，确保「优先使用本地元数据」是开启的；
- 修改后刷新媒体库。

**Q：封面显示不出？**

- 图片扩展名是 `.jpg` / `.jpeg` / `.png` 时 Jellyfin 一定能识别；
- 如果源图片是 `.webp`，Jellyfin 部分版本不支持，需要用外部工具转成 `.jpg`。

**Q：想跳过已经存在的 NFO？**

- 取消勾选「覆盖已有 NFO」，已存在的 `.nfo` 不会被重写。

**Q：`.nfo` 里的演员 `<role>` 是干什么的？**

- `Jellyfin` / `Kodi` 里 `<role>` 通常表示演员扮演的角色名；
- 本插件把演员的别名（如「张三（张三丰）」里的「张三丰」）放进 `<role>`，作为别名提示；
- 如果不需要别名，可以留空不填。

## 重要提醒

- **本插件只处理「嵌入单元格图片」格式**。如果你的封面是普通浮动图片，提取会失败；
- **本插件不修改原表格**，所有操作都是只读；
- **`movie_root` 下的文件夹名必须与表格里的番号一致**，否则会显示「未匹配」；
- 生成 NFO 前建议先备份 `movie_root`，虽然本插件不会删除任何文件，但批量写入时如果出错可能需要回滚。
