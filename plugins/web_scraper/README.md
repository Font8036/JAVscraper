# 爬虫插件（web_scraper）

去 javdb.com 抓取影片元数据，去 subtitlecat.com 搜索并下载中文字幕。内含两个独立的爬取源，各自有独立的配置和操作界面。

## 功能

| 源 | 作用 |
|---|---|
| **JavDB 信息** | 从 javdb.com 抓取演员、评分、类别、评论、封面，生成带封面嵌入的 Excel 报告 |
| **字幕猫** | 从 subtitlecat.com 搜索并下载中文字幕，生成结果 Excel 报告 |

两者共用一套 Playwright 依赖，可独立使用。

---

## 依赖

```cmd
conda activate private
pip install playwright openpyxl xlsxwriter httpx Pillow
playwright install msedge
```

| 包 | 用途 |
|---|---|
| `playwright` | 浏览器自动化 |
| `openpyxl` | 读取输入 Excel |
| `xlsxwriter` | 生成结果 Excel |
| `httpx` | 异步下载 JavDB 封面 |
| `Pillow` | 读取封面尺寸 |

`playwright install msedge` 需要下载浏览器驱动（几百 MB），**只需执行一次**。

完整版 exe 已内置以上依赖，无需手动安装。

## 安装与使用

插件随**完整版 exe**一起发布，主界面顶部会显示 **「3-爬虫」** 标签页：

```
1-扫描   2-移动   3-爬虫   4-Jellyfin NFO
```

点进去后内部有两个子标签页：

```
JavDB 信息   字幕猫
```

**所有配置项都在右下角的「配置」窗口中**。主界面的各子标签页只负责操作。点击状态栏右侧的「配置」按钮，切到对应的标签页即可。

## JavDB 信息

从 javdb.com 抓取影片元数据，生成带封面嵌入的 Excel 报告。

### JavDB 配置项

在**配置窗口**里切到「JavDB 信息」标签页：

#### 路径

| 字段 | 说明 |
|---|---|
| 站点地址 | 默认 `https://javdb.com/`，一般不用改 |
| 输入 Excel | 番号清单 |
| 封面目录 | 封面图片保存目录（不存在会自动创建） |
| 输出 CSV | 中间结果 CSV 路径 |
| 输出 Excel | 最终 Excel 报告路径 |
| 登录状态 | 登录状态文件路径（可留空） |

#### 运行参数

| 字段 | 默认 | 说明 |
|---|---|---|
| 显示浏览器窗口 | 开 | 是否显示浏览器窗口 |
| 浏览器 | msedge | `msedge` / `chrome` / `chromium` |
| 请求间隔(秒) | 1.0 | 每次请求之间的等待 |
| 超时(秒) | 60 | 页面操作超时，首次打开主页会用到 5 倍 |
| 重试次数 | 2 | 单个番号失败后的重试次数 |

#### 行为开关

| 字段 | 默认 | 说明 |
|---|---|---|
| 跳过已存在的封面 | 关 | 跳过已有封面文件，节省时间 |
| 退出时保存登录状态 | 关 | 退出时把登录状态回写到「登录状态」路径 |
| 完成时响铃 | 开 | 爬取完成时响一声 |
| 完成时发系统通知 | 关 | 完成时弹 Windows 通知 |

### JavDB 使用步骤

#### 1. 准备番号清单

新建一个 Excel 文件，**第一列**写入要刮削的番号，**一行一个**，不要表头：

```
ABP-123
SSIS-456
FC2-1234567
```

建议从「1-扫描」页的扫描结果里挑出 `✓` 的番号，或直接复制 `log/<时间戳>/extraction_table.csv` 里的「提取出的信息」列。

#### 2. 填写配置

打开配置窗口，切到「JavDB 信息」，按上面的表填好各项路径，点「应用」或「确定」。

#### 3. 登录 javdb（可选）

javdb 有部分信息需要登录才能看到。有两种方式：

**方式 A：导入浏览器 Cookie**

1. 在浏览器里安装 **Cookie-Editor** 或 **EditThisCookie** 扩展；
2. 打开 javdb.com，确认已登录；
3. 用扩展导出 cookies，**选 JSON 格式**；
4. 在配置窗口的「JavDB 信息」页里点 **「导入浏览器 Cookie」**，选中刚才导出的 JSON 文件；
5. 弹窗提示导入成功即可。

**方式 B：手动登录**

1. 在「3-爬虫」→「JavDB 信息」子 Tab 里点 **「启动浏览器」**；
2. 在弹出的浏览器窗口里慢慢登录；
3. **回到程序**，点 **「关闭浏览器」** —— 登录状态会自动保存到「登录状态」路径。

也可以跳过这一步，用游客模式跑，能抓到的信息会少一些。

#### 4. 开始爬取

切到主界面的「3-爬虫」→「JavDB 信息」，点 **「开始爬取」**。

进度表格逐行显示：

```
目标番号     实际番号     名称                     状态
ABP-123     ABP-123     某某标题                 ✓ 完成
SSIS-456    SSIS-456B   别的标题                 ⚠ 完成（番号不同）
FC2-…       —           —                        进行中…
XYZ-999     —           —                        ✗ 失败：timeout
```

**状态颜色**：

| 颜色 | 含义 |
|---|---|
| 绿色 `✓ 完成` | 刮削成功，且番号与目标一致 |
| 橙色 `⚠ 完成（番号不同）` | 刮削成功，但搜到的第一个结果番号与目标不符 |
| 红色 `✗ 失败：xxx` | 该番号未能抓取 |
| 蓝色 `进行中…` | 正在处理 |
| 灰色 `○ 已停止` | 用户手动停止 |

**如果开启了「显示浏览器窗口」**：会看到一个 Chromium 窗口自动操作。遇到验证码时手动点一下。

**中途想停**：点「停止」，已抓取的数据会保存。

#### 5. 生成 Excel

点 **「生成 Excel」**，几秒后弹窗提示完成。打开输出路径下的 `.xlsx` 文件查看。

也可以跳过爬取步骤，直接用已有的 CSV 生成 Excel——只要「输出 CSV」路径下的文件存在即可。

### JavDB 输出说明

#### 输出 CSV

「输出 CSV」路径下的 CSV 包含以下列：

| 列 | 内容 |
|---|---|
| 目标番号 | 用户输入的番号 |
| 链接 | 详情页 URL |
| 番号 | 详情页显示的番号 |
| 名称 | 标题 |
| 信息 | 详情页文本，用于二次解析 |
| 评论 | 评论文本 |

这是中间产物，用于追溯和重跑。想重新生成 Excel 时不必重新爬取。

#### 封面图片

「封面目录」下的图片按番号命名：`ABP-123.jpg`、`SSIS-456.jpg` 等。

#### 最终 Excel

Excel 的列布局：

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| 目标番号 | 番号 | 封面 | 名称 | 演员 | (空) | 评分 | 类别 | (空) | 评论 |

封面图片嵌入到 C 列，行高按图片宽高比自动计算。

**行颜色**：

| 颜色 | 含义 |
|---|---|
| 无底色 | 正常行，目标番号与刮到的番号一致 |
| **浅红 `#FFC7CE`** | 番号**刮削失败**，只有目标番号，其余留空 |
| **浅黄 `#FFF2CC`** | 目标番号与刮到的番号**不一致**，需要人工核对 |

**无评分但有链接时**，评分列显示「无评分」，链接仍然可点击。

### JavDB 结果校对

因为搜索逻辑是"点击第一个结果"，实际刮到的番号不一定与目标一致（可能是续集、同系列其他作品）。建议：

1. 打开 Excel，先扫一遍**浅黄**的行；
2. 对比「目标番号」与「番号」两列，判断是否是你要的那个；
3. 如果是误抓，删掉那行或手工修正；
4. **浅红**的行是彻底没抓到的，可以重跑（单独把它们的番号放进新的 Excel）。

## 字幕猫

从 subtitlecat.com 搜索并下载中文字幕，生成结果 Excel。

### 字幕猫配置项

在**配置窗口**里切到「字幕猫」标签页：

#### 路径

| 字段 | 说明 |
|---|---|
| 站点地址 | 默认 `https://www.subtitlecat.com/` |
| 输入 Excel | 番号清单（格式和 JavDB 一样） |
| 目标目录 | 下载的字幕保存到哪里（**平铺，不建子文件夹**） |
| 输出 Excel | 爬取完成后自动生成的结果表格 |
| 登录状态 | 一般留空即可，访问字幕猫通常不需要登录 |

#### 运行参数

| 字段 | 默认 | 说明 |
|---|---|---|
| 显示浏览器窗口 | 开 | 是否显示浏览器窗口 |
| 浏览器 | msedge | `msedge` / `chrome` / `chromium` |
| 请求间隔(秒) | 1.0 | 每次请求之间的等待 |
| 超时(秒) | 10 | 页面操作超时，首次打开主页会用到 5 倍 |
| 重试次数 | 2 | 单个番号失败后的重试次数 |
| 等待翻译(秒) | 30 | 点「翻译」后等待网站生成下载链接的最长时间 |
| 轮间等待(秒) | 3.0 | 重试等待翻译的番号时，每轮之间的等待时间 |

#### 行为开关

| 字段 | 默认 | 说明 |
|---|---|---|
| 退出时保存登录状态 | 关 | 退出时把登录状态回写到「登录状态」路径 |
| 完成时响铃 | 开 | 爬取完成时响一声 |
| 完成时发系统通知 | 关 | 完成时弹 Windows 通知 |

### 字幕猫使用步骤

#### 1. 准备番号清单

和 JavDB 一样：新建 Excel，第一列写番号，一行一个，无表头。

#### 2. 填写配置

打开配置窗口，切到「字幕猫」，填好各项路径与参数，点「应用」或「确定」。

#### 3. 开始爬取

切到「3-爬虫」→「字幕猫」，点 **「开始爬取」**。

工具会逐个番号：

1. 在 subtitlecat.com 里搜索；
2. 从搜索结果里按优先级挑一条；
3. 进入详情页下载；
4. 如果详情页没有下载按钮但有「翻译」按钮，会点一下，等网站生成后再下载。

进度表格逐行显示。**爬取完成后自动生成 Excel，不需要额外点按钮**。

### 字幕选择策略

工具会从搜索结果里挑一条最合适的下载，优先级从高到低：

1. **番号一致**：选中字幕的标题里包含目标番号（如搜 `ABP-285` 时优先选标题含 `ABP-285` 的）；
2. **有 👍 标记**：带 👍 的字幕更受用户认可；
3. **`translated from Chinese`**：优先选从中文翻译过来的（这类字幕通常更贴合原意）；
4. **下载量最高**。

**只要搜索结果不为空，就一定会选中一条**（即使番号都不一致）。

### 字幕猫输出说明

#### 结果表格的列

| 列 | 说明 |
|---|---|
| 目标番号 | 你输入的番号 |
| 搜索结果数量 | 该网站里搜到多少条（**数字带超链接**，点击直接跳转到网页） |
| 实际番号 | 选中字幕对应的番号（用本工具的扫描器提取） |
| 名称 | 字幕的标题（已去掉语言后缀） |
| 源语言 | 字幕翻译前的语言（中文显示，如"中文"、"英语"、"日语"） |
| 下载量 | 该字幕的下载次数 |
| 状态 | 见下 |

#### 状态说明

| 状态 | 含义 |
|---|---|
| 下载成功 | 正常下载完成，且番号一致 |
| 下载成功（番号不一致）| 下载完成，但选中的字幕是另一个番号的 |
| 未搜到 | 网站里没有该番号的结果 |
| 下载失败 | 详情页里既没有下载按钮也没有翻译按钮 |
| 下载失败（翻译超时）| 点了「翻译」按钮后等太久，网站还没生成下载链接 |
| 等待翻译 | 已点「翻译」，等待网站生成下载链接 |
| 已停止 | 用户手动停止 |

#### 行颜色

| 颜色 | 含义 |
|---|---|
| 无底色 | 正常 |
| **浅红 `#FFC7CE`** | 失败（未搜到 / 下载失败 / 翻译超时） |
| **浅黄 `#FFF2CC`** | 下载成功但番号不一致，需要核对 |

#### 下载的字幕文件

- 保存到「目标目录」，**平铺**（不建子文件夹）；
- 文件名与网站提供的原始名字一致（如 `ABC-123-zh-CN.srt`）；
- 这些字幕可以直接用本工具的「1-扫描」和「2-移动」功能整理到视频旁边。

### 关于「翻译」按钮

有些字幕在网站上只提供"翻译成中文"的按钮，需要点击后等网站生成中文版本，然后才会出现"下载"按钮。工具会自动处理：

- 点「翻译」→ 记下时间 → 过一段时间回来检查；
- 如果超过「等待翻译」秒数（默认 30 秒）网站还没生成，就记为失败；
- 「轮间等待」控制每轮检查之间隔多久（默认 3 秒）。

**对于队列很长的场景**：即使某个番号排到的时候已经超过等待上限，工具仍会在最后一轮**再尝试一次**——如果那时网站已经生成好了，照样能成功下载。

## 常见问题

**Q：主界面看不到配置项？**

- 所有配置都移到了配置窗口里。点击主界面右下角的「配置」按钮即可打开。

**Q：导入 Cookie 后，爬取时还是未登录？**

- 确认导出的 JSON 是从**已登录的浏览器**导出的；
- Cookie 有时效性，过期后需要重新导出；
- 有些扩展默认只导出当前站点，如果浏览的是镜像域名可能导出为空。

**Q：被 Cloudflare 拦截 / 无限验证码？**

- **开启「显示浏览器窗口」**，手动完成验证码；
- **不要贪快**：请求间隔保持 ≥ 1.0 秒；
- 长时间爬取建议中途休息；
- 使用登录状态能显著降低被拦频率。

**Q：JavDB 爬取很慢？**

- 每个番号通常需要 5~10 秒，100 个番号约 10~15 分钟；
- 主要耗时在等待页面加载和 Cloudflare 检查；
- 减少请求间隔会加快速度，但更容易被封。

**Q：封面下载失败？**

- 检查网络是否能访问 javdb 的 CDN；
- 检查封面目录是否有写权限；
- 部分番号可能本身就没有封面。

**Q：Excel 打开后图片不显示？**

- 确认封面目录下存在与番号同名的图片文件；
- 部分老旧 Excel 版本对 `embed_image` 支持不好，建议用 Excel 2016+ 或 WPS 打开。

**Q：JavDB 结果里有很多「番号不同」？**

- 说明搜索关键词没有精确匹配到你要的那个；
- 可以尝试用更完整的番号格式（如 `FC2PPV-1234567` 而不是 `FC2-1234567`）；
- 也可以手动在浏览器里搜一次，看 javdb 的第一个结果到底是什么。

**Q：JavDB 重跑时怎么跳过已经成功的？**

- 勾选「跳过已存在的封面」可以省去封面下载；
- 但没有"跳过已成功的番号"选项，每次都会重爬全部。可以手动从输入 Excel 里删掉已成功的番号再跑。

**Q：字幕猫下载的字幕，名字对不上视频？**

- 看生成的结果表格里状态是不是**浅黄底**的「下载成功（番号不一致）」；
- 这类行需要人工核对，或手动改字幕文件名；
- 如果番号一致但文件名不好看，可以用本工具的「2-移动」功能把字幕重命名。

**Q：字幕猫搜索到很多结果，为什么选中了另一个番号的？**

- 说明搜索结果里没有目标番号完全一致的条目；
- 工具会从"番号不一致"的候选里按优先级再挑一条（有 👍 > 中文翻译 > 下载量）；
- 想避免这种情况，可以用更完整的番号格式，或手动改字幕文件名。

**Q：字幕猫显示「下载失败（翻译超时）」？**

- 说明点了「翻译」按钮后，超过了「等待翻译」秒数网站还没生成下载链接；
- 可以增加「等待翻译」秒数（比如 60 或 120），或增加「轮间等待」秒数；
- 也可能是那个字幕本身无法生成中文版本。

**Q：生成报告时提示"报告生成失败"？**

- 常见原因：目标 Excel 文件正被 WPS / Excel 打开；
- 关闭那个文件后重新爬取，或换一个输出路径。

**Q：`.csv` 里为什么有目标番号与实际番号不一致的行？**

- 这就是搜索的客观结果，不是 bug；
- 见「JavDB 结果校对」一节。

## 重要提醒

- **首次跑建议开启浏览器窗口**，方便观察和手动过验证码；
- **登录状态文件包含你的身份凭证**，不要分享给他人，也不要提交到 git；
- **爬取频率不要过高**，既是为了避免被封，也是对网站的基本尊重；
- **下载的字幕版权归字幕作者所有**，请勿传播或商用；
- 本插件仅用于个人资料整理，请遵守相关网站的服务条款和当地法律法规。
