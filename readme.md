# AV 文件名刮削与整理工具

一个 Windows 桌面小工具，用于**从文件名中提取标准代码，并按代码批量移动、重命名文件**。所有操作都在图形界面完成，不需要懂编程，也不需要打开命令行。

## 这个工具能做什么

假设你有一堆文件名长这样的视频：

```
ABP-123 某某标题.mp4
SSIS_456 另一个标题.mkv
FC2-1234567.mp4
随手拍的一段视频.mp4
```

这个工具能：

1. **自动识别**哪些文件名里有标准代码（`ABP-123`、`SSIS-456`、`FC2-1234567`）；
2. **告诉你识别结果**——识别成功标绿色 `✓`，识别失败标灰色 `✗`；
3. **按代码把文件移动到指定目录**，可以按代码分文件夹，也可以用代码给文件重命名；
4. **一键撤回**——如果移错了，可以还原。

如果下载的是**完整版**，还多一个 JavDB 刮削功能：把一批番号交给它，它会去网站上抓取演员、评分、封面图，生成一张漂亮的 Excel 表格。

## 下载与安装

软件有两个版本，选一个下载即可：

| 版本 | 大小 | 包含什么 | 适合谁 |
|---|---|---|---|
| **核心版** | 约 15 MB | 扫描 + 移动功能 | 只想整理本地文件 |
| **完整版** | 约 200 MB | 核心功能 + JavDB 刮削 | 还要抓取网站信息 |

### 核心版

下载 `av-scraper-core.exe`，放到任意目录，双击运行。

### 完整版

下载 `av-scraper-full.zip`，解压到任意目录（比如 `D:\Tools\AVScraper\`），双击里面的 `av-scraper-full.exe`。

> ⚠ **重要**：完整版是一个文件夹，不要只把里面的 `.exe` 单独拷出来，会无法运行。

### 系统要求

- Windows 10 / 11
- 不需要安装 Python，不需要任何其他软件

## 第一次使用

1. **双击 exe 启动**。首次运行会在 exe 旁边自动生成 `config.json`（配置文件）和 `log/` 文件夹（日志）。

2. **切到「③ 配置」标签页**，改几个路径：

   | 配置项 | 填什么 |
   |---|---|
   | 默认扫描目录 | 你的视频文件所在的目录 |
   | 输出目录 | 一般留空即可（结果自动存到 `log/` 下） |
   | 目标目录 | 文件整理后要移到哪里 |

   改完点下方的「保存配置」。

3. **切到「① 扫描」标签页**，检查扫描目录对不对，点「开始扫描」。

到这里就基本能用起来了。详细流程见下一节。

## 日常使用流程

程序有三个主要标签页（完整版额外有第四个），按顺序操作即可。

### ① 扫描

这是整个流程的起点。

**操作步骤**：

1. 确认顶部的「扫描目录」是你的视频目录；
   - 第一次需要手动选，之后会自动记住上次用的目录；
   - 点击输入框会展开历史下拉，选之前用过的目录；
2. 点「开始扫描」；
3. 稍等片刻，结果会一行行显示在表格里。

**看懂结果**：

| 显示 | 含义 |
|---|---|
| `✓` **绿色** | 成功识别到代码 |
| `✗` **灰色** | 没识别到，保持原文件名 |

表格上方的状态栏会显示总数、成功数、提取率。

**小技巧**：

- 点击表头可以排序——比如点「状态」列，把 `✓` 和 `✗` 分开看；
- 每个扫描结果会自动存到 `log/<时间戳>/` 里，包括 JSON、文本报告、CSV 表格；
- 扫描不会修改任何文件，可以放心重复运行。

**如果 `✗` 太多**：

- 说明这些文件名里没有可识别的代码；
- 常见原因是文件名里缺少连接符（`-` 或 `_`）——比如 `ABP123` 而不是 `ABP-123`，这时需要手动改文件名；
- 识别规则详见「③ 配置」里的「已知字母前缀」。

---

### ② 移动

扫描完成后，切到这一页。

**操作步骤**：

1. 顶部「输入 JSON」应该已经自动填好了（来自上一次扫描）；
2. 确认「目标目录」；
3. **点「预览更改」**——这一步不会动文件，只是告诉你会发生什么；
4. 仔细检查表格里的每一行；
5. 确认无误后，点「执行移动」；
6. 弹窗确认后，文件开始移动。

**预览表格的颜色**：

| 颜色 | 含义 |
|---|---|
| 绿色 | 正常移动 |
| 灰色 | 跳过（目标已存在，不覆盖） |
| 红色 | 覆盖（目标已存在，会被替换）⚠ |

**移错了怎么办**：

点「撤回移动」，会按照上一次移动的记录把所有文件搬回原位。

> 撤回记录只保留**最近一次**。如果连续执行了多次移动，只能撤回最后一次。

---

### ③ 配置

所有设置都在这里，改完点「保存配置」立即生效，无需重启程序。

**主要配置项**：

| 配置 | 说明 |
|---|---|
| 默认扫描目录 | 打开程序时扫描页的默认值 |
| 输出目录 | 扫描结果保存到哪里；**留空则存到程序目录下的 `log/`** |
| 目标目录 | 文件移动到哪里 |
| 是否递归处理子文件夹 | 勾上则连子文件夹一起扫 |
| 连接符 | 前缀与数字之间的分隔符，默认 `-` 和 `_` |
| 支持的扩展名 | 哪些类型的文件参与扫描 |
| 已知字母前缀 | 识别规则的核心，每行一个前缀 |
| 移动到提取名子文件夹 | 勾上则每个代码建一个文件夹 |
| 启用重命名 | 勾上则用代码给文件改名 |
| 文件冲突处理 | `skip` 跳过 / `overwrite` 覆盖 / `rename` 自动加序号 |

**修改前缀**：

- 点击「已知字母前缀」文本框，每行加一个前缀；
- 也可以在一行里用逗号分隔；
- 加完后必须点「保存配置」；
- 新前缀立即对下一次扫描生效。

### ④ JavDB 刮削（可选）

**仅完整版有此功能**。

它的作用是：读一批番号 → 打开浏览器 → 自动去 javdb.com 抓取演员、评分、封面等信息 → 生成一张漂亮的 Excel 表格。

#### 准备工作

1. 准备一个 Excel 文件，**第一列**写入要刮削的番号，**一行一个**，不要表头。

   ```
   ABP-123
   SSIS-456
   FC2-1234567
   ```

2. 在插件配置里填好路径：
   - 输入 Excel：上面的文件；
   - 封面目录：下载的封面图存到哪里；
   - 输出 CSV：中间结果（爬到的原始数据）；
   - 输出 Excel：最终的漂亮表格；
   - 登录状态：见下方「登录 javdb」。

3. 点「保存配置」。

#### 登录 javdb

有些信息需要登录才能看到。如果你已经登录了 javdb：

1. 在浏览器里安装 **Cookie-Editor** 或 **EditThisCookie** 扩展；
2. 打开 javdb.com，确认已登录；
3. 用扩展导出 cookies，选 JSON 格式；
4. 在插件界面点「导入浏览器 Cookie」，选择刚导出的 JSON 文件；
5. 完成。

也可以不做这一步，直接用游客模式跑，但能抓到的信息会少一些。

#### 开始爬取

1. 点「开始爬取」；
2. 进度表格会逐行显示状态：

   ```
   目标番号    实际番号    名称              状态
   ABP-123    ABP-123    某某标题          ✓ 完成
   SSIS-456   SSIS-456B  别的标题          ⚠ 完成（番号不同）
   FC2-…      —          —                 进行中…
   ```

3. **番号不同**表示搜到的第一个结果不是你要的那个（可能是续集、同系列其他作品），打开 Excel 后可以人工核对；
4. 全部完成后点「生成 Excel」。

#### 重要建议

- **第一次跑建议开启「显示浏览器窗口」**——javdb 会弹验证码，需要你手动点一下；
- **不要贪快**——「请求间隔」默认 1 秒，改快容易被封；
- 遇到卡住可以点「停止」，已抓到的数据会保存。

## 常见问题

**Q：双击 exe 没反应 / 闪退？**

- 检查是否有杀毒软件拦截。Windows Defender 或国产杀软对 PyInstaller 打包的 exe 有时会误报，加到白名单即可；
- 完整版确认整个文件夹都在，没有单独拷贝 exe。

**Q：扫描时程序卡死？**

- 正常不会。如果卡住，多半是磁盘读得慢（尤其是机械硬盘或网络盘），等它跑完即可；
- 日志区能看到实时进度。

**Q：扫描结果里 `✗` 很多怎么办？**

- 打开「③ 配置」，确认文件名里的前缀在「已知字母前缀」列表里；
- 不在就加进去；
- 也检查文件名里是否有合法的连接符（`-` 或 `_`）。

**Q：移错了想反悔？**

- 点「撤回移动」即可。前提是 `log/move_operations.json` 还在，且没有执行过新的移动。

**Q：JavDB 插件显示「缺少依赖」？**

- 完整版不应该有这个提示。如果出现，说明打包有问题，请联系作者；
- 核心版看不到这个标签页，是正常的——这个功能只在完整版里。

**Q：想清空历史目录记录？**

- 关闭程序，用记事本打开 `config.json`，找到 `recent_scan_dirs` 和 `recent_target_dirs`，改成 `[]`，保存。

**Q：配置文件在哪？**

- 跟 exe 放一起，叫 `config.json`。所有设置都存在里面；
- 想完全恢复默认：删掉它，重启程序会自动生成一份新的。

**Q：日志和结果文件在哪里？**

- exe 旁边的 `log/` 文件夹里；
- 每次扫描会在 `log/<时间戳>/` 下生成三个文件；
- 这些文件不会被自动清理，想删就手动删。

## 重要提醒

- **移动是不可逆的物理操作**。虽然提供了撤回，但只在特定条件下有效（记录文件还在、之后没有执行过新移动）。**执行前务必点「预览更改」**，尤其看清红色的「覆盖」行。
- 扫描不修改文件，可以放心反复运行。
- 本工具仅用于本地文件整理。请确保所处理的文件来源合法，并遵守当地法律法规。
- 完整版体积较大（约 200 MB），因为内置了浏览器驱动。这是正常的，不是软件出问题。
- **不要单独拷贝完整版里的 exe**——整个文件夹要一起复制或移动。
