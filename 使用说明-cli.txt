使用说明（命令行版）
=====================

⚠ 本版本仅面向熟悉命令行的用户。
   不熟悉命令行的请用 JAVscraper_core（核心版）或 JAVscraper_full（完整版），
   它们双击即可运行，所有功能都有图形界面。

本程序不带图形界面，只能在 cmd / PowerShell 里用。
爬虫和 Jellyfin NFO 两个功能只在图形界面版本中提供。

1. 整个文件夹就是程序，不要单独拷贝 exe；放到任意目录即可，无需安装。
   首次运行会在同级目录生成 config.json 和 log\ 目录。
   用法：JAVscraper_cli.exe <子命令> [参数]

2. 常用子命令：
     scan    扫描目录，提取番号并导出 JSON / 文本报告 / CSV
     move    按扫描结果移动 / 重命名文件
     undo    撤回上一次移动
     config  查看当前配置（只读）

3. 会修改文件的操作默认先预览、再询问确认：
     move 不加 -y 时会问你一次；在脚本 / 计划任务里必须加 -y，否则拒绝执行。
     不确定时先加 --dry-run 看一眼再动手。

4. 与图形界面版本共用同一份配置（config.json、log\），两边可以互相撤回。
   命令行只读配置，要改配置请用图形界面版本的「配置」窗口。

5. 扫描结果默认保留最近 20 次，可用 --keep N 覆盖（0 = 不清理）。
   跨盘移动（复制 + 删除）会明显变慢，预览里会提示数量。

6. 退出码：0 成功；1 有文件没处理成功 / 被中断 / 被取消；2 参数用法问题。
   可以在脚本里用 %ERRORLEVEL% 判断。

示例：
   JAVscraper_cli.exe scan D:\videos --no-reports
   JAVscraper_cli.exe scan D:\videos D:\downloads          （一次扫多个目录）
   JAVscraper_cli.exe scan D:\videos --keep 5             （只留最近 5 次结果）
   JAVscraper_cli.exe move results.json -t E:\sorted --dry-run
   JAVscraper_cli.exe move results.json -t E:\sorted -y
   JAVscraper_cli.exe move results.json -t E:\sorted -y --part-naming
   JAVscraper_cli.exe undo -y
   JAVscraper_cli.exe --help
   JAVscraper_cli.exe move --help

更多说明见 https://github.com/Font8036/JAVscraper 的 README.md「命令行模式（CLI）」一节。
